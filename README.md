# Sistema-de-Gerenciamento-de-Lava-Carro

Este repositório tem como objetivo desenvolver um sistema de gerenciamento para uma lava carro, com foco no aprendizado e na prática de persistência de dados com Entity Framework Core e SQL Server, arquitetura de software, regras de negócio e revisão de Programação Orientada a Objetos (POO).

O projeto será pensado para simular um ambiente real de negócio, incluindo funcionalidades como cadastro de clientes, veículos,  agendamentos, histórico de atendimentos e relatórios. A proposta principal é aprofundar conceitos de modelagem de entidades, relacionamentos, migrations, consultas, separação de responsabilidades e boas práticas de desenvolvimento, utilizando C# como linguagem principal e SQL Server como banco de dados.
