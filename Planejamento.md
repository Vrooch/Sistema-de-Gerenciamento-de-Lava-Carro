# Sistema de Gerenciamento de Lava Carro

### Ideia principal:
```
Um sistema que permite o cliente se cadastrar, cadastrar seus carros e agendar sua lavagem. Também permite ao cliente verificar seus agendamentos e histórico de atendimento, além de cancelar os agendamentos.

A unidade deve ser capaz de acessar a agenda de atendimentos, adicionar agendamentos, cancelar e realizar a lavagem. Gerenciar e realizar a manutenção (cadastrar/inativar) veículos e clientes. Cadastrar novos empregados.
O sistema também deve permitir à unidade extrair dados como quantidade de clientes, de veículos, agendamentos...
```

> Nota: O sistema deve ser o mais simples possível, atendendo às premissas estabelecidas.

### Funcionalidades:
```
1. Clientes:
    - Gerenciar Cliente (conta):
        - Cadastrar conta;
        - Inativar conta;
        - Cadastrar veículo;
        - Inativar veículo;
        - Alterar senha
    - Gerenciamento de lavagens:
        - Agendar lavagem;
        - Cancelar lavagens
        - Ver agenda
        - Ver histórico gasto/lavagens;
2. Unidade:
    - Gerenciar lavagem:
        - Iniciar lavagem (a partir de um agendamento);
        - Finalizar lavagem;
        - Cancelar lavagem;
        - ver agenda;
        - Adicionar Agendamento;
        - Cancelar agendamento;        
    - Gerenciar clientes (contas):
        - Cadastrar Cliente;
        - Inativar Cliente;
        - Cadastrar veículo;
        - Inativar Veículo;
    - Relatórios;
        - Quantidade de clientes;
        - Quantidade de veículos;
        - Quantidade de agendamentos;
        - Quantidade de agendamentos cancelados;
        - Quantidade de lavagens;

        - Quantidade de clientes - Último mês (novos);
        - Quantidade de veículos - Último mês (novos);
        - Quantidade de agendamentos - Último mês;
        - Quantidade de agendamentos cancelados - Último mês;
        - Quantidade de lavagens - Último mês;
```
